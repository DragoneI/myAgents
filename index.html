Pourquoi choisir myAgents

Deux outils simples, pensés pour les entreprises qui n’ont pas le temps de gérer un logiciel compliqué.

  • Sur WhatsApp, là où sont vos clients

    Vos visiteurs et vos clients utilisent déjà WhatsApp. Neo et Veo s’appuient dessus au lieu de leur demander d’adopter un nouvel outil.

  • Disponible à toute heure

    Neo répond à vos visiteurs la nuit, le week-end et pendant vos congés, et note leurs coordonnées pour que vous les rappeliez.

  • Vous gardez le contrôle

    Rien n’est envoyé sans votre appui. Vous relisez chaque relance et vous la modifiez si vous le souhaitez.

  • Dans la langue de vos clients

    Neo répond en français, en arabe ou en anglais, selon la langue de votre visiteur.

  • Vos données restent à vous

    Chaque entreprise accède uniquement à ses propres données, avec un code d’accès personnel.

Comment démarrer

  1. Vous nous écrivez

    Un message sur WhatsApp pour nous décrire votre activité et choisir Neo, Veo ou les deux.

  2. Nous préparons votre outil

    Neo est réglé avec le nom, les services et le numéro de votre entreprise. Veo reçoit votre espace de suivi.

  3. Vous recevez votre accès

    Un code personnel pour Veo, une ligne à ajouter à votre site pour Neo.

Le premier mois est gratuit : vous testez avant de payer.

Questions fréquentes

Combien ça coûte ?

2 500 DH par agent, en un seul paiement, sans abonnement, à vie. Le premier mois est gratuit : vous testez avant de payer.

Dois-je installer une application ?

Non. Veo s’ouvre dans le navigateur de votre téléphone. Neo s’ajoute à votre site avec une seule ligne de code.

Les messages partent-ils tout seuls ?

Non. Veo prépare le message, vous le relisez et vous l’envoyez vous-même depuis votre WhatsApp. Vous gardez le contrôle sur chaque relance.

Mes données sont-elles protégées ?

Chaque entreprise accède uniquement à ses propres données, avec un code d’accès personnel.

En quelle langue répond Neo ?

Neo répond dans la langue de votre visiteur : français, arabe ou anglais.
